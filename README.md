# Pump_Selector
Simple Python tool that go through a pump catalogue based on user flow rate and pump head
# Features
-Choses pumps based on technical needs

-Sorts the products by flow rate

-Does some validation for inputs

# How to Run
1-Download pump_selector.py

2-Run the script

3-Enter the required flow rate and pump head

4-Look at the matching pumps :D
